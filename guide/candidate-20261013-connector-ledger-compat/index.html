2026.10.13 Connector 기록 호환성 복구 이미지

기존 Connector 효과 기록을 안전하게 읽도록 보완한 이미지의 워커별 적용·검사 결과와 남은 CI 검사를 구분합니다.

이미지와 적용 상태

날짜는 정식 제품 버전 번호가 아닙니다. 이 이미지는 시스템 이벤트·설치 스킬 자동업데이트 이미지의 다음 소스에서 만들었고, 이번 항목에는 Connector 기록 읽기 호환성 수정만 기록합니다. 콘솔의 v0.1.0으로 두 이미지를 구별할 수 없으므로 정확한 이미지 식별은 비공개 배포 기록에서 대조합니다.

무엇이 막혔나

worker00의 기존 Connector 효과 기록에는 과거에 저장된 부가 메타데이터가 있습니다. 이전 이미지의 엄격한 읽기 방식은 이 추가 필드를 만나면 기록 전체를 거부해, 관련 없는 새 조회까지 진행하지 못했습니다. 보존된 기록은 기존 한도인 2,000건이며 JSON 자체가 손상됐거나 제공자 토큰이 거부됐다고 확인된 사례가 아닙니다. 사용자에게 보일 증상은 Connector 조회가 시작되기 전에 내부 기록 검증 오류로 차단되는 것입니다.

복구 범위와 보호 규칙

새 읽기 방식은 이름과 크기·형식이 확인된 기존 부가 메타데이터만 허용합니다. 알 수 없는 필드와 핵심 값이 잘못된 기록은 계속 거부합니다. 메타데이터가 권한, 승인, 실제 작업 인자나 처리 결과를 바꾸도록 허용하지 않습니다.

기존의 확인 필요 기록은 그대로 보존하고 같은 요청의 실행을 차단합니다. 그 기록과 무관한 새 조회만 계속 진행할 수 있습니다. 결과가 불확실한 변경 작업의 중복 실행 방지도 유지합니다. 기록 삭제·초기화·재등록, 권한 확대, 승인 절차 우회는 하지 않으며 2,000건 보존 한도 정책도 바꾸지 않습니다. Console 메뉴·폼의 화면 변경은 없습니다.

확인된 검사와 제한

정확한 새 소스에서 집중 Connector 검사, 유형 검사·빌드, Wiki 부정 사례 20건, 최소 안정성 검사와 깨끗한 소스의 전체 개발 검증을 통과했습니다. 적용 전 실제 worker00의 보존 기록 2,000건을 새 순수 읽기 검사기로 읽기 전용 대조했고, 적용 후 새 실행 이미지의 실제 리더로도 모두 읽었습니다. 그중 확인 필요 상태 1건은 보존된 차단 상태로 남았습니다. 기록 파일을 수동 수정·초기화하지 않았습니다.

원격 Registry와 서버 배치 이미지는 로컬 불변 빌드와 일치했고, worker00 적용 후 보존 검사는 13건 모두 통과했습니다. 별도 진단 요청에서 올바른 프로젝트를 탐색한 뒤 실제 gitlab.api.request 성공 기록을 확인해 기존 기록 검증 오류가 새 조회 전체를 막지 않음을 확인했습니다. 앞선 잘못된 프로젝트 경로의 HTTP 404는 별개이며, 최종 CI 파일·시험·Wiki 반영과 이벤트 전달은 아직 확인되지 않았습니다. 이벤트 수신은 꺼져 있고 발행자는 0명, 자동 정책은 기본 꺼짐입니다. 재관찰된 프로세스 정리 경고는 이 이미지 적용으로 근본 해결됐다고 보지 않습니다. Codex 0.162.0, Claude 2.1.183, Kimi 0.29.2는 앞선 이미지와 같습니다.

수용 결과와 남은 검사

  1. 통과: worker00의 정확한 이미지·건강·재시작 0과 보존 파일·설정의 적용 전후 일치를 확인했습니다. worker0에서는 나중에 같은 실행 이미지·건강·재시작 0만 별도로 확인했으며 보존 파일·업무 결과는 미검증입니다.
  2. 통과: worker00의 기존 효과 기록 2,000건을 실제 새 리더가 읽고, 확인 필요 기록 1건은 차단 상태로 남았습니다. 임의 승인·삭제·재실행은 하지 않았습니다.
  3. 조회 경로 확인: worker00의 승인된 별도 진단에서 실제 GitLab Connector 성공 기록을 확인했습니다. 앞선 잘못된 경로의 404를 전체 복구 실패나 CI 성공으로 해석하지 않습니다.
  4. 미완료: CI 구성 작업의 최종 상태, 파일·시험·Wiki 반영과 이벤트 전송을 각각 확인해야 합니다. 결과가 불확실한 변경 작업의 중복 실행 차단도 격리 시험 범위로 남깁니다.

설치된 이미지와 Connector 조회 경로의 수용을 CI 통합 완료로 확대하지 않습니다.

화면 증거 범위

새 UI 변경 없음입니다. 이 수정은 내부 Connector 기록 읽기 호환성에 한정되므로 이전 화면을 새 버전의 캡처로 재사용하거나 새 화면을 임의로 만들지 않습니다. 실제 조회 성공은 운영 기록으로 확인했으나 공개용 화면 캡처는 미확보입니다. CI 최종 Task 결과가 나오면 민감정보 없이 별도 기록합니다.

시작 조건

worker00의 정확한 이미지 적용·건강·보존 검사 13건, 실제 효과 기록 2,000건 읽기와 별도 GitLab Connector 성공 기록을 확인했습니다. 확인 필요 기록 1건은 차단 상태로 남고 CI 구성 작업은 아직 진행 중입니다.

실행 순서

  1. worker00의 정확한 실행 이미지와 건강·재시작 상태를 새로 읽고 다른 워커의 이미지와 구분합니다.
  2. 기존 Connector 기록 2,000건과 확인 필요 1건의 차단 상태를 읽기 전용으로 대조합니다. 임의 승인·삭제·재실행하지 않습니다.
  3. 승인된 무관한 읽기 요청으로 실제 GitLab Connector 성공 기록과 최종 Task 상태를 각각 확인합니다. 잘못된 프로젝트 경로의 404와 기록 검증 오류를 구분합니다.
  4. CI 구성 작업의 최종 파일·시험·Wiki 반영 및 이벤트 접수·처리는 별도로 판정합니다. 불확실한 변경 효과의 중복 실행 차단은 격리 시험에서 대조합니다.

통과 기준

worker00에서 이 이미지와 보존 기록·GitLab 조회 경로는 확인됐습니다. 확인 필요 기록은 계속 차단돼야 하며 CI 구성과 이벤트 전달은 각각 최종 결과가 확인될 때까지 미완료로 남깁니다.

남길 증거

정확한 내부 이미지, worker00 적용·검사 시각, 건강 상태, 기록 수와 확인 필요 상태, 승인된 새 조회의 Task·Connector 결과 및 실패 코드를 비공개 운영 기록에 남깁니다. 공개 자료에는 내부 이미지 식별과 기록 내용을 싣지 않습니다.
