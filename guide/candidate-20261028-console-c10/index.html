이전 후보와 달라진 점

영역C10 변경
로그인·배치허용된 로컬 계정·Google 로그인 진입, 브랜드 정보, 탐색/작업 패널의 배치·크기 조절을 새 Console에 연결했습니다. 브라우저 배치 선호는 서버 설정이 아닙니다.
설정새 Console에서 네 설정 상세를 열고 나머지는 기존 Console로 이동합니다. Google 관리자와 일반 사용자 권한을 구분합니다.
Claude Code Plan기존 Console의 장기 인증에서 연결 클릭 시 팝업을 먼저 예약하고, 인증 주소가 늦거나 팝업이 차단되면 수동 열기 경로를 제공합니다.
입력·저장 보호같은 계정의 상태 알림은 비밀번호 초안을 지우지 않으며 계정 전환·로그아웃·권한 상실 때 보호된 초안을 폐기합니다. 결과 불명 쓰기는 정식 재조회로 대조하고, 프로필 이름 변경만으로 없는 어댑터 매핑을 만들지 않습니다.

새 Console의 설정 연결 범위

설정 → 시스템 → 파일 업로드 정책과 설정 → 보안 → 로컬 사용자는 Google 관리자 전용입니다. 설정 → 런타임 → 실행 프로필과 설정 → 어댑터 → 런타임 어댑터는 일반 계정에서 조회할 수 있으나 변경은 관리자만 합니다. 설정 사용·검증 안내에 화면별 순서와 실패 처리를 정리했습니다.

자격·비밀값, 예약, 플러그인, 커넥터, 스킬, 지식, 도구, 업데이트 등 다른 상세 설정은 아직 완전히 이전되지 않았습니다. 기존 Console에서 열기를 사용하고, 새 설정 목록의 설명만으로 저장 가능하다고 판단하지 않습니다.

Claude 장기 인증 연결 보완

관리자는 기존 Console의 설정 → 어댑터 → Claude Code Plan → 설정 → 장기 인증에서 브라우저 인증으로 연결을 사용합니다. 주소가 아직 준비되지 않았다면 연결 상태 새로고침으로 확인합니다. 팝업이 보이지 않으면 화면에 나온 허용된 주소를 복사하거나 인증 페이지 열기를 선택합니다. 코드가 요구될 때만 제출합니다. 기존 장기 인증 절차도 참고하세요.

실제 Claude OAuth 승인·토큰 발급·유료 모델 요청은 검증하지 않았습니다. CLI 상태만으로 모델 응답 성공을 판정하지 않습니다.

확인된 검사와 한계

정확한 소스의 깨끗한 개발 전체 검사 596건 통과·실패 0·차단 0, Wiki stale 0·오류 0, linux/amd64 이미지 빌드·식별, 패키지 자산 1,724개 대조와 인증 파일 부재를 확인했습니다. 이미지의 CLI는 Codex 0.162.0, Claude Code 2.1.183, Kimi Code 0.29.2입니다. 로컬 API/브라우저 검사는 합성 인증·자료를 사용했습니다. 동일 이미지의 Registry 원격 식별과 22:35(KST) 서버 이미지 단독 공급, 관리 워커 8개의 정확한 업데이트 제안을 확인했습니다. 공급 당시 컨테이너 13개의 ID·설정·마운트·재시작 횟수는 유지됐습니다.

C10 지정 워커 Update, 실제 사용자 화면·보존 자료·OAuth/모델 결과와 Portable ZIP 수용은 별도 단계입니다. 기존 자동설정은 변경하지 않았으며 제안 available만으로 적용 완료를 주장하지 않습니다.

정확한 이미지 적용 뒤 재현 검사

  1. 적용 전 워커 이미지·건강·기존 설정·사용자·프로필 수를 비공개 기록에 남기고, Update 뒤 정확한 새 실행 이미지와 보존을 대조합니다.
  2. 관리자/일반 사용자로 로그인해 네 설정의 표시·읽기·변경 권한을 시험합니다. 같은 계정의 갱신 중 비밀번호 초안은 유지되고 계정 전환·로그아웃 뒤에는 지워져야 합니다.
  3. 가상 값으로 업로드 정책의 네 한도를 저장·재조회·복원합니다. 충돌과 결과 불명에서 자동 중복 저장이 없는지 확인합니다.
  4. 시험용 로컬 사용자·프로필의 생성, 목록·revision·기본값, 비밀번호 재설정/세션 무효화, 이름 변경 때 매핑 보존을 확인합니다.
  5. 런타임의 현재 선택과 설정/유효/권장 용량을 읽고, 승인된 시험 변경이 새 요청에만 적용되는지 확인합니다.
  6. Claude 인증 주소 지연·팝업 차단 복구를 확인하고, 실제 OAuth/모델 결과는 수행한 경우에만 따로 기록합니다. 데스크톱·모바일 화면을 비밀값 없이 촬영합니다.

이 절차는 적용 후 수용 기준이며 현재 통과 기록이 아닙니다.
