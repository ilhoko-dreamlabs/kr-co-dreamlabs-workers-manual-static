공급·적용 단계

정확한 비교 기준은 앞선 Git 계정 권한 방식 이미지입니다. 아래 상태는 단계별 증거이며 서버 배치나 업데이트 제안만으로 현재 워커가 새 기능을 쓴다고 판정하지 않습니다.

14:21(KST) 읽기에서 관리 워커 8개 모두 정확한 새 이미지 제안이 사용 가능했고 정상·활성 작업 0·대기 중 업데이트 없음이었습니다. 기존 13개 컨테이너의 식별·상태와 worker0의 환경·마운트·보호 설정은 보존됐습니다. 강제 실행·수동 Update·재시작·정책 변경은 없었습니다. worker1과 dl-dev-worker의 기존 자동 업데이트 정책은 유지되고 예약 적용이 허용됐으므로 이후 실제 적용 여부는 각 워커의 실행 이미지로 다시 판정해야 합니다. 제안의 사용 가능 상태는 조회 시점의 결과이며 지속을 보장하지 않습니다.

이번 이미지에서 달라진 점

설정 → 시스템 → 파일 업로드의 대화 첨부파일 한도를 Claude의 지원되는 MCP 파일 응답에도 연결했습니다. 실제 원본 파일 바이트와 Base64 전송량을 구분해 제한된 크기로 처리하며, 실행 시작 시 유효한 설정과 리비전을 고정합니다. 변경된 설정은 다음 Claude 실행부터 적용되고 진행 중인 실행의 한도를 바꾸지 않습니다.

파일 크기·전송 한도가 먼저 실패했는데 종료 처리 중 CONTEXT_NATIVE_PROTOCOL_INVALID로 덮이던 문제를 고쳤습니다. Chat과 RRA는 한국어·영어로 파일 크기, 전송 용량, 형식 문제와 안전한 후속 확인을 구분합니다. 화면 위치·설정·오류별 조치와 시험 절차를 제공합니다.

관리자 설정과 기존 자료

관리자는 현재 유효값·출처·허용 범위를 확인하고, 허가된 시험 환경에서만 저장·재조회합니다. 이 필드는 Console·RRA·Mattermost의 새 대화 첨부파일과 다음 Claude 실행의 지원되는 MCP 파일 결과에 공통으로 작용합니다. 기존 첨부파일을 지우지 않으며 설정/자료 마이그레이션과 운영 설정 자동 증설도 없습니다. 프로필·스킬 한도, 실행 슬롯·권한·인증, 컨텍스트 요약 알고리즘과 번들 CLI 버전은 바뀌지 않았습니다.

외부 MCP·Claude·서비스 자체 한도와 모델 내부 메모리까지 늘리는 개선은 아닙니다. 실패한 작업을 자동 재실행하지도 않습니다. 결과가 불확실한 외부 작업은 원본 서비스의 실제 효과를 먼저 확인하세요.

확인된 검사와 한계

깨끗한 소스 기준 478건 통과·실패 0·차단 0입니다. 이미지 내부 애플리케이션·출처와 주요 회귀, Node 22.23.3 및 고정된 Codex 0.162.0·Claude 2.1.183·Kimi 0.29.2 실행을 격리 검사했습니다. 실제 후보 이미지의 패키지된 코드와 Claude 2.1.183을 합성 loopback MCP/모델에 연결해 한도 5 MiB/원본 3 MiB 성공, 2 MiB/3 MiB에서 파일 크기 오류만 보존, 5 MiB/5 MiB 경계 성공을 확인했습니다. 각 경우 도구 호출은 한 번, 운영 변경·호스팅 모델 호출은 0회였습니다.

한국어·영어 안내와 모바일 설정의 제품 브라우저 검사는 통과했습니다. 다른 제공자·모든 파일 형식·운영 계정의 실제 MCP 결과를 전면 보장하지 않으며, 새 이미지의 지정 워커 기능·화면 수용은 아직 없습니다.

적용 뒤 직접 테스트하기

  1. 시험 워커가 이 후보를 정확히 실행 중인지 이미지·건강·기존 자료를 확인합니다. Registry 또는 업데이트 제안만으로 적용을 통과로 기록하지 않습니다.
  2. 관리자는 설정 → 시스템 → 파일 업로드의 현재 한도·한국어/영어·좁은 화면을 확인하고, 일반 사용자는 이 설정을 조회·변경할 수 없는지 대조합니다. 허가된 시험 설정은 저장→재조회→복원 순서로 기록합니다.
  3. 안전한 합성 파일을 반환하는 승인된 MCP 경로에서 한도 아래·초과·경계 크기를 새 Claude 실행마다 시험합니다. 시작 당시 설정·리비전과 실제 원본 크기, Task 결과를 비교합니다.
  4. Chat과 RRA의 첫 파일 크기 오류와 안내가 프로토콜 오류로 덮이지 않는지 확인합니다. 파일 결과를 만든 도구의 외부 효과를 읽은 뒤에만 다시 요청합니다.

비공개 기록에는 워커·정확한 실행 이미지·시각·설정 전후 값과 리비전·안전한 시험 파일의 크기·Task/도구 결과·가린 실제 화면을 남깁니다. 운영 설정 변경과 업데이트는 이 페이지 게시로 승인되지 않습니다.
