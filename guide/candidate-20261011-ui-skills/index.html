콘솔 화면에서 바뀌는 점

상태와 아이콘을 정확히 읽기

상태 배지는 사용 불가·읽기 전용을 성공으로 보이게 하지 않도록 구분합니다. 아이콘에는 텍스트를 남기고 한국어·영어 접근성 이름을 제공하도록 보완했습니다. 녹색 표시만 보지 말고 실제 상태 문구와 마지막 결과를 함께 읽으세요.

설정·차트·Wiki 표시

설정 구역은 내용 높이에 맞춰 표시하고, 데이터가 0건인 차트는 값을 꾸며내지 않습니다. Wiki 그래프를 새로고침하는 동안 마지막 정상 그래프를 유지하며, 새 조회 실패를 성공 갱신으로 표시하지 않습니다.

탐색과 업데이트 진행

최상위 탐색은 처음 열 때 접힌 상태로 시작합니다. 기존에 사용자가 열어 둔 워커 간 요청의 하위 메뉴 상태와 실시간 상태 전달은 보존합니다. 전체 업데이트 화면은 접수된 요청의 결과를 제한된 시간 동안 관찰하고, 결과가 불확실하면 중복 실행을 유도하지 않도록 보완했습니다.

이 항목들은 새 이미지의 소스·합성 브라우저 검사 결과입니다. 현재 운영 워커의 화면에서 모두 보인다는 뜻은 아닙니다.

스킬 설치 실패를 단계별로 확인

관리자용 설정 → 스킬에서 목록, 미리보기, 다운로드, 검증, 활성화, 설치 결과 재조회 중 어느 단계에서 실패했는지 한국어·영어 안내로 구분합니다. 마지막 실패 진단은 화면을 다시 열어도 확인할 수 있고, 감사 기록에도 남깁니다. 오류 코드·대상 스킬·버전을 확인한 뒤 해당 단계의 원인을 조치하세요. 같은 설치 버튼을 반복해서 누르는 것으로 해결됐다고 판단하지 않습니다.

기존 스킬 보호업데이트가 중단됐을 때 기존 정상 패키지를 유지하는 경로를 읽기 검증으로 보완했습니다. 실패 후에는 기존 설치 기록과 실제 파일, 활성화 상태를 각각 재조회합니다. 설치·활성화·요청별 로딩·어댑터 적용은 여전히 별개입니다.

호환성과 알려진 한계

  • Codex 0.162.0, Claude 2.1.183, Kimi 0.29.2는 앞선 이미지와 동일합니다. 이번 이미지의 CLI 업그레이드가 아닙니다.
  • 상태 데이터 마이그레이션이나 의미 요약 정책 자동 활성화는 포함되지 않습니다. 이전 이미지 리더를 사용한 호환 검사 20건은 합성 실행이며 운영 롤백 결과가 아닙니다.
  • 별도 스킬 Registry의 tunnel 1.3.1 후보는 아직 게시되지 않았습니다. 기존 카탈로그 패키지 오류가 이 Worker 이미지 하나로 해결됐다고 판단하지 않습니다.
  • 데스크톱·모바일의 새 실제 화면과 스킬 설치·업데이트 업무 결과는 아직 확인하지 않았습니다. 기존 캡처는 이 이미지의 화면 증거로 사용하지 않습니다.

과거 업데이트 준비 기록

2026년 10월 11일 밤 worker0의 Settings → Runtime → Whole Update 화면에는 UNIFIED_QUEUE_STATE_LOCK_UNCERTAIN 차단 사유가 표시됐고 Run Whole Update 버튼이 비활성화돼 있었습니다. 사용자가 별도로 승인한 운영 복구에서 원본 잠금 증거를 보존하고 큐·상태 파일 152개의 내용이 바뀌지 않았음을 확인했습니다. 같은 당시 실행 이미지로 다시 시작한 뒤 10월 12일 00:57(KST) 건강 상태·작업 0건·잠금 부재를 확인했습니다. 이어 로그인 콘솔을 Refresh하자 차단 사유가 없고 Run Whole Update 버튼이 활성화돼 있었습니다. 당시 버튼과 확인창은 누르지 않았으므로 그 관찰만으로는 이 이미지의 적용 근거가 아니었습니다. 10월 13일 별도 읽기에서 worker0 실행 이미지임을 확인했습니다. 일반 사용자는 잠금 파일을 직접 다루지 말고, 실행 전 현재·대상과 차단 사유를 다시 조회하세요.

확인된 검사와 범위

정확한 새 이미지 소스의 전체 개발 검증은 430건 통과·실패 0·차단 0입니다. 유형 검사·빌드, Wiki 부정 사례 20건과 최소 안정성 검사를 통과했습니다. 소스 기반 Chromium 화면 검사 43건에서 여러 화면 너비의 상태·아이콘·레이아웃을 확인했고, 실제 이전 이미지 리더와의 저장 상태 호환 검사 20건이 통과했습니다.

브라우저 검사는 격리된 시험 화면이며 실제 worker0 화면 캡처가 아닙니다. 이번 10월 13일 읽기는 실행 이미지와 건강 상태만 확인했고, 실제 모델 호출이나 운영 스킬 설치·업데이트의 기능 결과는 아직 수용하지 않았습니다.

실제 화면과 기능 테스트

  1. 이 정확한 과거 이미지를 실행하는 시험 워커의 이미지·건강 상태·보존 데이터를 확인합니다. 현재 worker0의 다음 이미지 결과를 이 버전의 시험 결과로 대체하지 않습니다.
  2. 일반 사용자 화면을 데스크톱·좁은 화면에서 열어 접힌 첫 탐색, 상태 문구와 아이콘 이름, 설정 구역 높이, 0건 차트, Wiki 새로고침 중 그래프를 실제로 촬영합니다.
  3. 관리자 화면에서 스킬 목록·설치·활성화·새 요청의 실제 적용을 각각 확인합니다. 실패 사례는 승인된 격리 시험에서만 만들고 실패 단계·재로그인 후 진단·기존 패키지 보존을 대조합니다.
  4. 전체 업데이트 화면의 현재·대상과 차단 사유를 새로고침 후 확인합니다. 이후 시스템 이벤트 이미지로의 대상 할당은 이 이미지 자체의 기능 수용과 분리합니다.

worker0의 과거 실행 확인만으로 이 페이지의 화면·업무 기능까지 통과로 표시하지 않습니다.

실행 순서

  1. 시험 워커의 정확한 실행 이미지·건강 상태를 확인하고 worker0의 현재 이미지와 구분합니다.

  3. 관리자 화면의 스킬 목록·미리보기·설치 결과·활성화·새 요청 적용을 구분합니다. 실패 진단의 단계·재로그인 후 표시·기존 패키지 보존은 승인된 격리 시험에서 확인합니다.
  4. 업데이트 진행의 시간 제한·불확실 결과·중복 요청 방지는 별도 승인된 시험에서 한 번의 요청 기록과 결과를 대조합니다.

통과 기준

worker0 과거 실행 이미지 확인과 정확한 시험 워커의 기능·화면 수용을 구분합니다. 상태 표시·실제 작업 결과·기존 스킬 보존을 각각 검증해야 기능 통과로 기록합니다.
