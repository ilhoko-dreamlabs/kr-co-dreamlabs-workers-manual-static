프로젝트와 대화 연결하기

프로젝트의 목적·지침·상태를 확인하고 관련 세션을 묶습니다.

실제 화면 캡처확인일 2026.10.01읽기·검사 약 5분

1프로젝트 양식 확인하기

왼쪽 프로젝트 옆 ＋를 선택합니다. 프로젝트 이름, 프로젝트 AGENTS.md 지침, 프로젝트 구분, 상태를 입력합니다. 프로젝트 구분은 목표달성·상시진행·기타, 상태는 진행·완료 항목이 보입니다.

2지침 적용 범위 이해하기

프로젝트 지침은 워커 전역 지침과 안전 경계 뒤에 적용되며, 이미 진행 중인 턴에는 소급되지 않습니다. 지침에 비밀번호나 API 키를 입력하지 않습니다.

3프로젝트 대화 보기

왼쪽 프로젝트 항목을 펼쳐 관련 세션을 확인합니다. 대시보드의 Projects 관점에서는 프로젝트별 세션·완료·오류 지표를 읽을 수 있습니다.

시작 조건

프로젝트 생성 권한이 있을 때만 고유한 시험 이름으로 진행합니다.

실행 순서

  1. 새 프로젝트 양식의 이름·구분·상태·지침 필드를 확인합니다.
  2. 간단한 시험 프로젝트를 저장하고 목록에서 다시 엽니다.
  3. 시험 세션을 연결한 뒤 프로젝트 목록과 세션 헤더를 비교합니다.

통과 기준

저장한 값과 연결한 세션이 다시 열어도 일치해야 합니다. 양식만 보이면 생성 검증은 미완료입니다.

남길 증거

시험 프로젝트 이름/ID, 저장값, 연결 세션 ID를 기록합니다.
