긴 대화에서도 현재 질문을 우선 보존

긴 대화의 입력 길이를 더 정확하게 계산하고, 선택적으로 들어오는 스킬·Wiki·Memory·작업공간 자료에 입력 예산을 나눕니다. 현재 질문, 필수 지시, 권한 관련 내용이 부가 자료 때문에 밀려나지 않도록 순서를 정리했습니다.

과거 대화를 압축하더라도 원문, 생성된 요약, 요청별 실제 맥락, 실패 진단을 구분해 확인할 수 있게 보완했습니다. 이 변경은 기존 원문이나 History를 삭제하지 않습니다. 이전에 worker0에서 관측된 짧은 후속 질문의 입력 초과 차단을 겨냥한 수정이지만, 같은 조건의 운영 대화를 다시 검사하기 전에는 해결을 실제 결과로 판정하지 않습니다.

요약 정책: 기본값과 선택 기능 구분

기본 정책인 자동 처리 켜짐·추출식 요약·제한 시간 20초는 바뀌지 않았습니다. 모델이 의미를 해석해 요약하는 방식은 관리자가 같은 어댑터·모델 사용을 명시적으로 선택할 때만 사용합니다. Codex·Claude·Kimi 경로에는 도구 없는 요약 호출, 시간 제한, 취소와 결과 형식 검사를 보완했습니다.

60초 격리 테스트의 의미52·96·140개 메시지로 만든 합성 장문 대화를 각 어댑터·모델에서 3차례 비교했으며, 명시적으로 60초를 준 조건에서 원문 대비 의미 품질을 확인했습니다. 기본 20초 설정에서도 모두 성공하거나 실제 업무 대화에서 같은 품질을 낸다는 뜻은 아닙니다. 실패 시 추출식 대체 결과와 실패 원인을 따로 확인해야 합니다.

한 번의 업데이트와 이전 버전 호환

기존 버전이 읽을 수 있는 기본 상태와 새 버전의 비공개 형식 맥락을 함께 보존합니다. 시험용 이전 이미지의 실제 리더를 사용한 저장 상태 호환 검사 20건이 통과했습니다. 관리자 설정의 나중 변경이나 이미 끝난 결과를 되돌리지 않으며, 인증·History·Wiki를 초기화하지 않습니다.

구버전으로 돌아가면 기존 추출식/전체 입력 방식으로 동작합니다. 새 의미 요약 기능이 구버전에서도 작동한다는 뜻은 아닙니다. 선택 입력 일부가 생략된 상태로 고정된 요청은 구버전에서 안전하게 차단하고, 새 버전을 다시 적용하면 복원하도록 설계했습니다. 관리자는 기본 상태, 비공개 기록, 확인 기록을 함께 백업하고 상태 파일을 임의로 삭제하지 않아야 합니다.

확인된 검사와 범위

정확한 이미지 소스에서 전체 개발 검증 424건 통과·실패 0·차단 0, Wiki 음성·최소 안정성 검사, 최종 이미지의 이전 리더 호환 검사 20건을 확인했습니다. 이미지 파일 1,274개의 출처와 Codex 0.162.0, Claude 2.1.183, Kimi 0.29.2를 격리 검사했습니다. 이미지의 생산 의존성 npm audit 결과는 0건이며, 운영체제나 모든 CLI 구성요소의 취약점이 0이라는 의미는 아닙니다.

worker0의 실행 이미지·건강 상태는 확인했지만 실제 업무 세션과 배포 후 브라우저 화면, 긴 대화의 기능 결과는 아직 검증하지 않았습니다. 새 화면 캡처도 미촬영입니다.

사용자와 관리자가 할 일

일반 사용자

이 정확한 이미지를 실행하는 시험 워커에서 안전한 대화의 짧은 후속 질문과 최종 답변, 컨텍스트 정보 화면의 원문·요약·요청별 사용 범위를 비교합니다. worker0의 현재 이미지 결과를 이 과거 이미지의 수용 결과로 대체하지 않습니다.

관리자

대상 워커의 정확한 이미지와 건강 상태를 먼저 확인합니다. 기본 정책값을 기록하고, 의미 요약을 시험할 때만 같은 어댑터·모델 옵션과 별도 제한 시간을 명시한 뒤 복원합니다. 백업 단위와 이전 버전 호환을 확인하되 실제 롤백은 별도 운영 절차로 다룹니다.

적용 후 남은 기능 테스트

  1. 지정 워커의 실행 이미지·건강 상태·보존된 세션을 다시 확인하고 이 이미지와 일치하는지 기록합니다.
  2. 관리자 화면에서 맥락 정책 기본값인 자동 처리·추출식 요약·20초를 재조회합니다. 설정값을 바꾸지 않았다면 의미 요약이 기본 활성화된 것으로 판정하지 않습니다.
  3. 비밀값 없는 긴 시험 대화에서 짧은 후속 질문을 보내 최종 상태와 응답을 확인합니다. 같은 조건의 과거 차단 사례와 비교하되 실패가 사라졌는지 실제 결과로 기록합니다.
  4. 컨텍스트 정보 화면에서 원문, 요약, 요청별 맥락과 실패 진단을 구분하고, 스킬·Wiki·Memory·작업공간 입력의 선택·생략 이유를 확인합니다. 데스크톱·모바일 실제 화면을 새로 촬영합니다.
  5. 별도 승인된 격리 시험에서만 같은 어댑터·모델 요약과 60초 제한을 켜 원문 대비 결과, 취소와 추출식 대체를 비교하고 원래 정책으로 복원합니다.

이 검사를 마치기 전까지 로컬 이미지 검사나 60초 합성 대화 결과를 운영 워커의 기능 통과로 표시하지 않습니다.

실행 순서

  1. 시험 워커의 정확한 실행 이미지·건강 상태·보존된 세션을 확인합니다.
  2. 기본 정책의 자동 처리·추출식 요약·20초를 재조회하고, 안전한 긴 시험 대화에서 짧은 후속 질문의 최종 상태와 답변을 확인합니다.
  3. 컨텍스트 정보 화면에서 원문·요약·요청별 맥락과 선택 입력의 사용·생략 이유를 확인합니다.
  4. 관리자가 명시적으로 같은 어댑터·모델을 선택한 격리 시험에서만 60초 의미 요약·취소·대체 결과를 비교하고 정책을 복원합니다.
  5. 이전 버전 호환과 백업 단위는 별도 운영 절차로 대조하되 임의 상태 삭제나 롤백은 하지 않습니다.
