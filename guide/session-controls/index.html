세션 목록과 대화 관리

최근 세션·외부 세션을 찾아 대화를 이어서 확인합니다.

실제 화면 캡처확인일 2026.10.01약 3분 읽기

1세션 목록 펼치기

왼쪽 세션에서 최근 세션 또는 외부 세션을 펼칩니다. 원하는 대화를 선택하면 해당 세션의 메시지가 열립니다. 제목이 비슷하면 세션 검색에서 문장 일부를 사용합니다.

2이전 대화 확인하기

요청과 최종 응답을 함께 확인합니다. 대화를 다시 여는 것만으로 작업이 재실행되지는 않습니다. 후속 요청은 같은 대화의 입력란에서 보낼 수 있습니다.

3필요한 내용 복사하기

메시지 옆의 메시지 복사 버튼으로 해당 요청 또는 답변을 복사할 수 있습니다. 복사한 내용에 개인정보나 비밀값이 포함되었는지 공유 전에 확인하세요.
