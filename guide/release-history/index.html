2026.10.19 GitLab REST fallback 업데이트 후보

GitLab Connector 오류를 원인과 변경 효과에 따라 구분하고, 준비된 Connector를 우선하면서 서버 자격으로 독립 승인된 REST 경로를 지원합니다. 확실히 효과가 없는 실패에만 승인된 대체 경로를 한 번 사용하고 결과 불명 쓰기의 자동 재전송과 재시작 후 중복 변경을 막습니다. 읽기 전용 GET 처리와 gitlab-work 번들 스킬·RRA 안내도 보완했습니다. 불변 이미지 빌드·격리 검사, Registry 식별, 10월 19일 18:36(KST) 서버 이미지 단독 배치와 18:37(KST) 관리 워커 8개의 대상 제안을 확인했습니다. 당시 기존 컨테이너는 바뀌지 않았고 업데이트 제출도 없었습니다. 이후 실행·실제 계정의 GitLab 기능 결과와 새 운영 캡처는 별도 확인이 필요합니다.
