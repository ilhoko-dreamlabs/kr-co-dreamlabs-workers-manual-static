2026.11.20 Console Next 기능·복구 로컬 후보

Console Next 기능의 로컬 검증과 worker0 자료 복구 준비를 이미지 단계별로 확인합니다.

로컬 이미지·전체 검사 1,124건 / Registry·워커 적용 전확인일 2026.11.20읽기·검사 약 5분
바로 이동
후보 상태이전 이미지 이후 변경자료 호환성과 복구확인한 검사적용 후 재현캡처 상태직접 테스트
로컬 이미지 · 지정 워커 미적용이 항목은 10월 31일 중앙 로그인 이미지 뒤에 만든 별도 linux/amd64 로컬 후보입니다. 날짜는 공식 제품 버전 번호가 아닙니다. 11월 20일 worker0은 읽기 전용 확인 시 이전 C10 계열 이미지로 실행 중이었으며, 이 후보의 공급·제안·적용은 확인되지 않았습니다.

비교 기준은 10월 31일 중앙 로그인 로컬 이미지입니다. 기능 구현과 그 이미지가 어느 워커에서 실행되는지는 별도 확인 항목입니다. Registry·서버·제안·적용은 모두 후속 단계입니다.

이전 이미지 이후 변경

영역이번 소스에 포함된 동작상세 안내
Console NextChat·프로젝트·Wiki·파일·대시보드·승인과 Queue, 검색·공개 실행 기록, 예약·시스템·업데이트 화면을 확장했습니다. 370개 추적 항목 중 358개가 로컬 검증 완료이며 1개는 부분 구현, 11개는 정책·소유자·외부 제품 조건으로 차단되어 있습니다.구현 상태와 남은 범위
설정환경 변수, Worker Base, 실행 제한·런타임, 어댑터 인증·API 자격, 연결과 스킬 관리의 새 Console 조작을 추가했습니다. 역할·revision·저장 후 재조회가 각 화면에 적용됩니다.설정 사용법
연결·RRA 대상외부 서비스의 개별 연결과 현재 대화 선택, 사용 위치/기본 연결, 별도 RRA 대상 Worker 설정을 다룹니다. 설정만으로 외부 권한이나 요청 승인이 생기지 않습니다.연결 사용법
스킬설치·카탈로그·소스·업로드·업데이트·제거와 사용 가능성·로딩 방식·예산·전역 지침을 분리했습니다.스킬 사용법
공개 페이지프로필의 공개 소개 화면과 편집·미리보기·확인·되돌리기 경계를 추가했습니다. 공개는 별도의 명시적 작업입니다.공개 페이지 확인

로컬 검증 수는 실제 Worker 적용, 유료 제공자 응답 또는 모든 370개 기능 완료를 뜻하지 않습니다. 특히 PLAN-12 outbound RRA 첨부 전달은 아직 구현 공백입니다.

자료 호환성과 복구

운영 worker0의 기존 Chat·RRA·설정 자료를 보존하기 위해 적용 전 정확한 이미지, 네 보존 마운트, RRA 저장 형식과 백업·복구 가능성을 확인했습니다. 승인된 정지 시간에 암호화 백업을 만들고 분리된 로컬 볼륨으로 복원해 소유권·모드·내용을 비교한 기록이 있습니다. 이는 후보 이미지를 worker0에 적용했다는 뜻이 아닙니다.

이전 이미지로 단순 되돌리기는 안전한 복구 절차로 확정되지 않았습니다. 새 형식으로 기록한 뒤 오래된 리더가 읽지 못하거나 뒤에 쓴 내용이 누락될 수 있습니다. 실제 업데이트에는 호환 복구 이미지, 독립 보관과 대상별 승인·검증 절차가 먼저 필요합니다. 일반 사용자는 화면에서 임의로 업데이트를 반복하지 말고 관리자에게 상태를 확인하세요.

확인한 검사와 한계

정확한 소스에서 개발 전체 검사 1,124건 통과·실패 0·차단 0, 타입 검사·빌드, 정적 문서 검사와 로컬 이미지 내부 검사·CLI 18개 점검을 확인했습니다. 격리 자료 복구 검사는 네 마운트와 RRA 저장 자료를 대상으로 했습니다. 초기 전체 검사 시 Playwright 모듈 경로 문제로 실패한 실행은 기존 설치 모듈을 지정한 재실행으로 복구되었고, 원래 실패 기록은 유지했습니다.

Registry push·서버 공급·업데이트 제안·지정 워커 적용·실제 사용자 로그인·제공자 실행은 없습니다. 당시 이미지의 의존성 권고는 뒤따른 보안 패치 이미지와 구분합니다. 새 Console의 화면 캡처는 아직 실제 Worker에서 얻지 못했습니다.

승인된 적용 뒤 직접 테스트

  1. 대상 워커의 기존 이미지·건강·작업·자료와 승인된 복구 증거를 기록합니다. 정확한 후보가 실제로 적용된 뒤 실행 이미지와 상태를 다시 읽습니다.
  2. 관리자와 일반 사용자로 로그인하여 새 설정·연결·스킬의 표시·변경 권한, 모바일 조작과 보호된 자료 정리를 비교합니다.
  3. Chat·RRA의 기존 세션과 후속 대화, 프로젝트·Wiki·파일·예약·설정의 보존 수를 전후 대조합니다. 시험 요청은 승인된 가상 자료만 사용합니다.
  4. 설정 저장·충돌·결과 불명에서 canonical 재조회와 중복 제출 방지를 확인합니다. 외부 제공자·모델 결과는 실제 실행한 경우에만 별도 판정합니다.
  5. 데스크톱과 모바일의 정확한 이미지 화면을 촬영하고 비밀값·개인 정보를 가립니다.

이 목록은 적용 뒤 수용 기준이며 현재 통과 기록이 아닙니다.

캡처 상태

화면 미촬영 · 이 로컬 후보의 실제 Worker UI는 촬영하지 않았습니다. 이전 이미지의 화면을 최신 운영 캡처로 표시하지 않습니다. 설정·연결·RRA 대상·스킬의 실제 후보 UI를 로컬 합성 데이터로 촬영해 각 사용법 페이지에 붙였습니다. 운영 화면은 아닙니다. 390px 캡처에서 일부 설명과 연결 ID의 오른쪽 잘림이 확인돼 모바일 수용은 미완료입니다.

시작 조건

11월 20일 첫 번째 로컬 Console Next 이미지를 정확히 식별합니다. 공급·적용 전이므로 기능 검사는 승인된 시험 적용 뒤에만 진행합니다.

실행 순서

  1. 로컬 전체 검사 1,124건과 Registry·서버·제안·적용 상태를 따로 읽습니다.
  2. 적용 전 자료와 복구 증거를 준비하고 정확한 이미지 실행·건강·보존 자료를 대조합니다.
  3. 관리자/일반 사용자 설정, Chat·RRA 후속 대화, 스킬·연결을 가상 자료로 검사합니다.
  4. 이전 이미지로 단순 복귀할 수 있다는 가정을 하지 않고 승인된 복구 계획을 확인합니다.

통과 기준

이미지 단계와 실제 기능 결과가 구분되고 자료·권한이 보존됩니다. RRA outbound 첨부는 미구현으로 남습니다.
