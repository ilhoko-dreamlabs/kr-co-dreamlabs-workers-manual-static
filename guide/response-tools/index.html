도구 영역 찾기선택 세션의 응답 원문 읽기Codex 공개 요약의 부분·최종 상태RRA 결과와 맥락 확인하기직접 테스트
최신 화면 재촬영 전이 페이지의 캡처와 클릭 결과는 2026년 10월 1일 worker00 기준입니다. 이후 좌측 탐색과 일부 설정 UI가 바뀌었습니다. 현재 배포의 화면 증거로 사용하지 말고, 실행 검사에서는 최신 메뉴와 실제 결과를 새로 기록하세요. 새 탐색 메뉴 안내

1도구 영역 찾기

왼쪽 도구 영역에서 응답 원문, 대화 맥락, 정보를 찾습니다. 10월 1일 실제 콘솔에서 응답 원문과 정보 버튼은 확인했습니다. 2026.10.15 이미지의 대화 맥락 도구 메뉴 이동은 소스로 확인했고, 10월 16일 worker0 실행·건강까지 확인했으나 새 도구 화면은 미촬영입니다.

2선택 세션의 응답 원문 읽기

2026.10.15 통합 이미지의 도구 → 응답 원문에서는 선택한 세션의 응답 타임라인을 채널·실행 기록으로 좁히고 접힌 기술 상세를 펼칠 수 있습니다. 세션을 바꾸면 그 세션의 기록이 보여야 합니다. 보존 기간 만료나 기록 없음은 없는 내용으로 채우지 않고 상태를 표시합니다. 일반 사용자에게 비공개 추론·내부 원문이 노출되지 않아야 합니다. worker0 실행 이미지는 확인했지만 상세 화면의 운영 캡처와 실제 제공자 결과는 미확보입니다.

3Codex 공개 요약의 부분·최종 상태

2026.10.16 이미지는 Codex 네이티브 실행기가 실제 내보낸 공개 요약을 응답 원문과 Chat·RRA 진행 기록에 표시합니다. 생성 중 부분 요약은 최종 요약으로 교체되고, 실행 중 재진입·새로고침 후에도 같은 공개 기록을 다시 읽을 수 있어야 합니다. 비공개 내부 추론은 수집하지 않으며, 옛 기록에 없던 요약 텍스트는 복원되지 않습니다. 10월 19일 worker0 실행 이미지·건강은 확인됐지만 실제 Codex 제공자 응답과 운영 캡처는 아직 없습니다.

4RRA 결과와 맥락 확인하기

RRA 결과는 안전한 Markdown으로 표시하고 공개 진행 상태는 재접속 후 다시 읽습니다. 도구 → 대화 맥락에서 현재 대화 범위를 확인하며, 정보에서는 Task 식별자와 최종 상태를 대조합니다. 스크립트가 실행되거나 다른 세션 기록이 섞이면 통과로 기록하지 않습니다.

시작 조건

정상 종료된 가상 회의 메모 시험 세션을 엽니다.

실행 순서

  1. 도구 → 응답 원문을 열어 선택 세션의 답변과 타임라인을 비교합니다.
  2. 통합 이미지에서는 채널·실행 기록 필터, 접힌 기술 상세, 기록 부재/만료 상태를 확인합니다.
  3. 2026.10.16 이미지가 실행 중인 시험 워커에서 새 Codex Chat·RRA 요청의 실제 공개 요약 부분 표시→최종 교체→실행 중 재진입·새로고침 뒤 보존을 검사합니다. 옛 업무 요청을 재실행하지 않습니다.
  4. 도구 → 대화 맥락과 정보를 열어 현재 세션·Task 식별자·최종 상태를 확인합니다.
  5. RRA 시험 결과의 Markdown과 재접속 후 공개 진행 기록을 확인합니다.

통과 기준

원문과 표시 답변이 같은 작업을 가리키고, 다른 세션이나 비공개 추론이 섞이지 않아야 합니다. 새 Codex 공개 요약은 실제 네이티브 출력일 때만 나타나고 최종값이 부분값을 교체해야 합니다. 위험한 Markdown HTML은 실행되지 않고 최종 상태가 결과 카드와 일치해야 합니다.

남길 증거

세션·Task·RRA 요청 식별자, 선택 필터, 부분/최종 공개 요약과 재진입 전후, 기록 부재 상태 및 정보 화면의 상태를 기록합니다.
