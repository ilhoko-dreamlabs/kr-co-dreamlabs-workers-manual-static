바로 이동
대상과 권한 확인로그인·화면 배치설정 목록과 기존 화면파일 업로드 정책로컬 사용자실행 프로필런타임 어댑터Claude 장기 인증충돌·결과 불명 복구테스트 기록·캡처직접 테스트
C10 공급 후보 사용 절차 · 실제 화면 미촬영이 페이지는 10월 28일 C10 이미지의 소스·격리 검사·Registry/서버 공급과 8개 업데이트 제안을 기준으로 합니다. 해당 이미지의 지정 워커 적용은 확인되지 않았습니다. 현재 운영 화면과 다르면 정확한 실행 이미지를 먼저 확인하세요.

대상과 권한 확인

  1. 시험 워커의 이미지·건강·기존 설정값을 비공개 기록에 남깁니다. 이 후보가 실제 적용되지 않았다면 아래 조작을 운영 통과로 기록하지 않습니다.
  2. Google 관리자 계정과 일반 로컬 사용자 계정을 구분합니다. 파일 업로드 정책·로컬 사용자 목록/변경은 관리자 전용이고, 실행 프로필·런타임 정보는 일반 사용자가 읽을 수 있으나 수정은 관리자 전용입니다.
  3. 실제 비밀번호·토큰 대신 승인된 시험 계정과 자료를 사용합니다. 변경 전 값·revision을 기록하고 복원 계획을 정합니다.

로그인과 화면 배치

  1. Worker의 HTTPS /console을 엽니다. 허용된 인증 방식에 따라 사용자 이름·비밀번호 → 로그인 또는 Google로 로그인이 보입니다. 어느 방식도 표시되지 않으면 사용 가능한 로그인 방식이 없습니다를 기록하고 관리자에게 문의합니다.
  2. 로그인 후 Worker 이름·프로필 이미지가 예상 대상과 맞는지 읽습니다. 모바일에서는 탐색 패널을 열어 같은 목적지를 확인합니다.
  3. 데스크톱에서 탐색/Workbench 경계를 드래그하거나 Workbench 최대화·Workbench 원래 크기로를 사용합니다. 새로고침 뒤 배치 선호를 확인하되, 브라우저 저장이 차단되어도 서버 설정이나 업무 자료 오류로 해석하지 않습니다.

같은 계정의 상태 갱신은 열려 있는 설정과 비밀번호 초안을 유지해야 합니다. 다른 계정으로 전환하거나 로그아웃하면 보호된 초안과 이전 계정의 설정 화면이 지워져야 합니다.

설정 목록과 기존 화면 이동

상단 설정을 열어 항목의 연결됨, 일부 연결됨, 기존 Console 사용 표시를 읽습니다. 실제 새 Console 상세는 런타임 → 실행 프로필, 어댑터 → 런타임 어댑터, 보안 → 로컬 사용자, 시스템 → 파일 업로드 정책 네 곳입니다. 나머지 항목에서는 기존 Console에서 열기를 사용합니다. 주소는 /console?ui=legacy입니다.

저장하지 않은 값이 있으면 목록으로 돌아가기나 닫기에서 폐기 확인이 나옵니다. 연결됨은 화면/API 연결 상태이며 실제 설정 변경이나 모델 실행 성공의 증거가 아닙니다.

관리자: 파일 업로드 정책

  1. 설정 → 시스템 → 파일 업로드 정책을 엽니다. 현재 값·허용 범위를 먼저 기록합니다.
  2. 첨부파일 최대 크기, 프로필 원본 최대 크기, 프로필 변환본 최대 크기, 스킬 패키지 최대 크기를 각각 확인합니다. 단위는 MiB이고, 입력 범위는 화면의 서버 제공값을 따릅니다.
  3. 승인된 시험 범위에서 한 값만 변경하고 저장을 누릅니다. 저장·확인 완료는 저장 응답과 다시 읽은 canonical 값이 일치할 때의 판정입니다. 새로고침으로 revision·네 값을 다시 대조합니다.
  4. 승인된 작은 시험 파일로 새 업로드에 적용되는지 보고, 원래 값으로 복원·재조회합니다. 이미 시작한 실행이나 기존 파일을 소급 변경한 것으로 해석하지 않습니다.

변경 충돌이면 입력을 보존한 채 최신값과 비교합니다. 적용 여부 확인 필요, 다시 조회 불가 또는 감사 기록 경고가 나오면 저장을 반복하지 말고 정식 값을 확인하세요. 일반 사용자에게는 정책 조회/수정이 제공되지 않습니다.

관리자: 로컬 사용자

  1. 설정 → 보안 → 로컬 사용자에서 목록·사용 가능 상태·세션 버전을 읽습니다. 일반 계정은 이 목록을 열람하거나 변경할 수 없습니다.
  2. 시험 계정의 사용자 이름, 표시 이름, 초기 비밀번호를 입력하고 사용자 생성을 선택합니다. 이름은 소문자/숫자로 시작하는 3–64자이며 이후 소문자·숫자·점·밑줄·하이픈을 사용할 수 있습니다. 비밀번호는 12–256자입니다. 목록 재조회로 생성 여부를 확인합니다.
  3. 시험 계정의 사용 중지·다시 사용, 비밀번호 재설정 → 새 비밀번호 → 비밀번호 변경을 각각 확인합니다. 중지·비밀번호 변경은 기존 로컬 세션을 무효화하므로 이전 세션으로 보호된 화면에 접근할 수 없어야 합니다.
  4. 삭제는 되돌릴 수 없는 별도 확인 작업입니다. 승인된 시험 계정에만 수행하고 목록에서 사라졌는지 읽습니다.

비밀번호 원문은 저장 뒤 다시 표시되지 않습니다. 같은 계정의 unrelated 상태 알림으로 입력 중인 비밀번호가 지워지면 C10 기대 동작과 다릅니다. 결과 불명은 새로고침으로 목록과 revision을 먼저 확인하고 같은 작업을 자동 반복하지 않습니다.

실행 프로필: 목록·편집·기본값

  1. 설정 → 런타임 → 실행 프로필에서 현재 프로필, Worker 기본값과 어댑터 매핑 수를 읽습니다. 일반 사용자는 읽기 전용입니다.
  2. 관리자는 프로필 만들기에서 이름·설명과 지원 확인된 어댑터의 모델·추론 수준·응답 속도를 명시적으로 고릅니다. 지원하지 않음과 확인되지 않음은 선택 가능으로 꾸미지 않습니다. 없는 어댑터 매핑은 이름 변경·복제·언어 전환만으로 생겨서는 안 됩니다.
  3. 프로필 저장 뒤 목록을 다시 읽습니다. 저장된 선택 미리보기는 저장된 설정의 해석이지 모델 실행 결과가 아닙니다. 필요하면 Worker 기본 실행 프로필 → 기본값 저장을 확인하고, 이미 접수된 요청의 스냅샷은 유지되는지 봅니다.
  4. 삭제 전 삭제 준비 → 영향 다시 확인에서 직접 연결과 표시할 수 없는 연결을 구분합니다. 필요한 대체 선택을 지정한 뒤 확인 후 삭제를 선택합니다. 이미 접수된 요청의 설정은 바뀌지 않습니다.

revision 충돌은 편집값을 유지하고 최신값을 재조회합니다. 저장 결과가 불명확하면 새 저장을 반복하지 않고 정식 상태로 재조정합니다. Console·RRA Key·Mattermost·예약의 상속과 접수 스냅샷은 실행 프로필 상세에서 별도로 확인하세요.

런타임 어댑터: 선택과 용량 읽기

  1. 설정 → 어댑터 → 런타임 어댑터에서 현재 런타임 선택, 선택 세대, Worker 최대 동시 실행을 읽습니다. 각 어댑터의 설정 용량, 유효 용량, 권장 용량과 준비 상태를 구분합니다. 권장 용량은 현재 설정값이 아닙니다.
  2. 일반 사용자는 조회만 합니다. 관리자가 승인된 시험 어댑터를 바꾸려면 런타임으로 선택 → 런타임 변경 확인을 읽고 확인합니다. 변경 직전 서버가 준비 상태·권한을 다시 확인합니다.
  3. 변경 후 새로고침에서 canonical 선택과 세대를 대조합니다. 준비되지 않음이면 기존 선택이 유지되어야 하며, 변경은 새 요청에만 적용됩니다. 접수된 요청의 런타임 세대는 바뀌지 않습니다.

인증·비밀값·상세 설정과 용량 편집은 이 새 화면에서 제공되지 않습니다. 인증·비밀값·상세 설정은 기존 Console에서 열기를 사용하세요. 결과 불명에서는 동일한 변경을 다시 누르지 말고 새로고침으로 현재 선택을 확인합니다.

기존 Console: Claude 장기 인증

  1. 기존 Console에서 열기 → 설정 → 어댑터 → Claude Code Plan → 설정 → 장기 인증으로 이동합니다. Google 관리자만 상태 조회·연결·제거를 조작합니다.
  2. 브라우저 인증으로 연결 → 연결 시작을 선택합니다. 새 창을 먼저 확보해 팝업 차단 가능성을 줄입니다. 인증 주소가 아직 준비되지 않았습니다가 보이면 연결 상태 새로고침으로 주소가 나올 때까지 확인합니다.
  3. 새 창이 차단되거나 닫혔다면 화면의 허용된 인증 주소를 복사하거나 인증 페이지 열기를 선택합니다. Claude가 요청할 때만 인증 코드를 제출합니다. 완료 뒤 상태 확인과 다음 Claude 요청의 최종 결과를 별도로 확인합니다.

장기 OAuth 토큰·코드·인증 주소의 민감한 매개변수를 캡처에 넣지 않습니다. CLI 상태만 확인 · 실제 모델 요청 미검증 표시는 실제 제공자 성공이 아닙니다. 기존 파일 로그인은 유지되며 Remote Control·claude.ai 커넥터에는 이 토큰을 사용하지 않습니다.
